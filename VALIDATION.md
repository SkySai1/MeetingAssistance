# Проверка milestone

Дата: 2026-09-12. Машина: Apple Silicon/macOS, Swift 6.3.3, Command Line Tools.

## Подтверждено

- `swift build` и `swift build -c release` проходят.
- 12 тестов Swift Testing проходят через команду с путями CLT, приведённую в `Scripts/test.sh`.
- `swift run` обнаруживает `Микрофон MacBook Pro` и `BlackHole 2ch`, разрешая текущие ID динамически.
- Два AUHAL-захвата работают одновременно на 48 кГц. Трёхминутная проверка завершилась без ошибок колбэков и разрывов sample-time.
- Речь в микрофон меняла только YOU; синтезированная речь, направленная явно в BlackHole, меняла REMOTE, оставляя YOU на уровне фонового шума.
- Короткая русская фраза REMOTE распознана целиком; 9,88 секунды аудио обработаны за 1,77 секунды.
- Несколько трёхминутных прогонов REMOTE завершены без роста очереди, с задержкой завершения ASR примерно 0,7–1,8 секунды и без точных повторов событий.
- Отсутствующий/повреждённый токенизатор приводит к локальной ошибке. Сетевой fallback токенизатора исключён через адаптер публичного протокола.

## Phase 6–7: ядро и базовый SwiftUI

- Аудио/ASR выделены в `MeetingAssistantCore` через настройки SwiftPM без переноса существующих файлов.
- Один `MeetingSession` используется CLI и GUI. Аргументы, сигналы и терминальный вывод остались в CLI; ядро публикует статусы, уровни и подтверждённые события.
- SwiftUI: подготовка, выбор источников и папок локальной модели, проверка уровней, живая встреча, Start/Stop, копирование текста, обработка ошибок и завершение при закрытии приложения.
- 16 автоматических тестов проходят, включая остановку до запуска, защиту от повторного запуска сессии, валидацию конфигурации вне CLI, завершение обоих потоков и ограниченный буфер GUI.
- Финальные debug/release-сборки проходят без предупреждений в исходниках проекта. `.build/MeetingAssistant.app` собран, `Info.plist` и подпись проверены (`plutil`, `codesign --verify --deep --strict`).

### Реальное приложение SwiftUI

Запущен собранный `.app` с `--validate-gui`. Это проверка настоящего окна и его view model с реальными аудиоустройствами, без автоматизации мыши/клавиатуры. Отчёт `.build/validation/gui/report.json`: `result: passed`.

- Тест уровней получает обновления YOU и REMOTE; после остановки текст отсутствует.
- Остановка сразу после Start безопасна; повторный Start во время работы не создаёт ещё одну встречу.
- При одновременной тестовой речи распознаны оба источника, 4 подтверждённых события в хронологическом порядке без дублей.
- До Stop получено 3 события; после завершения обработки — 4. Последняя фраза REMOTE поступила при завершении ASR, её текст сохранён.
- После остановки таймер и текст больше не изменяются.
- Следующая встреча стартует с новым транскриптом и корректно останавливается.
- Глобальные устройства ввода/вывода остались прежними.

## Ограничения проверок

- Глобальный выход macOS при проверке был `Динамики MacBook Pro`, а не многовыходное устройство. Тесты направляли речь в BlackHole явно. Перед реальной конференцией необходимо выбрать настроенное многовыходное устройство в macOS/приложении.
- Синтезированная речь и акустическая проверка YOU не заменяют проверку реальной конференции с наушниками. Пауза, история, диаризация и AI-контекст относятся к последующим этапам.
